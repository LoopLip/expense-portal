# Портал командировок и расходов (Expense Portal)

## Описание проекта

Веб-приложение для учета командировочных расходов. Позволяет сотрудникам создавать отчеты о командировках, фиксировать расходы по категориям, просматривать статусы заявок и общие суммы.

*Примечание: Функция автоматического извлечения данных из фотографий чеков (OCR) запланирована в будущих версиях, сейчас данные вводятся вручную.*

## Пользовательские сценарии и экраны

В приложении реализованы следующие основные экраны и сценарии:

### 1. Главная (Список отчетов)

* **Сценарий:** Пользователь открывает приложение и видит список всех своих отчетов о командировках.
* **Функционал:** Отображение названия, дат, итоговой суммы и статуса отчета. Переход к детальному просмотру.
* **Скриншот:** `docs/screenshots/01_dashboard.png`

### 2. Создание отчета

* **Сценарий:** Пользователь возвращается из новой командировки и создает черновик отчета.
* **Функционал:** Форма ввода основных данных (название, даты, цель). Валидация обязательных полей.
* **Скриншот:** `docs/screenshots/02_create_report.png`

### 3. Детали отчета

* **Сценарий:** Пользователь или бухгалтер просматривает детализацию расходов по конкретной командировке.
* **Функционал:** Просмотр общей информации и таблицы с перечнем всех расходов (дата, категория, сумма, описание).
* **Скриншот:** `docs/screenshots/03_report_details.png`

## Стек технологий

### Frontend (реализовано)

* **React** + **TypeScript** — основа интерфейса
* **Vite** — сборщик проекта
* **React Router** — клиентская маршрутизация
* **Ant Design** — библиотека UI-компонентов

### Backend (планируется в Лабораторной №2)

* **Python** + **FastAPI** — серверная часть
* **PostgreSQL** — база данных
* **SQLAlchemy** — ORM для работы с БД

## Установка и запуск Frontend

### 1. Клонирование репозитория

```bash
git clone https://github.com/LoopLip/expense-portal.git
cd expense-portal
```

### 2. Установка зависимостей

```bash
npm install
```

Эта команда установит все необходимые пакеты из `package.json`:

* `react` и `react-dom` — основа React
* `react-router-dom` — маршрутизация
* `antd` — UI-библиотека
* `@ant-design/icons` — иконки

### 3. Запуск в режиме разработки

```bash
npm run dev
```

После запуска открой в браузере адрес, указанный в терминале (обычно `http://localhost:5173`).

### 4. Сборка для продакшена

```bash
npm run build
```

Готовые файлы будут в папке `dist/`. Их можно разместить на любом статическом хостинге.

## Модель данных (предварительная)

На данном этапе используются демонстрационные данные. В Лабораторной №2 будет реализована полноценная модель данных в PostgreSQL:

### Сущности проекта

**1. Report (Отчет о командировке)**
   * `id` — уникальный идентификатор
   * `title` — название командировки
   * `start_date` — дата начала
   * `end_date` — дата окончания
   * `status` — статус (Draft, Submitted, Approved)
   * `total_amount` — итоговая сумма
   * `description` — описание/цель

**2. Expense (Расход)**
   * `id` — уникальный идентификатор
   * `report_id` — связь с отчетом (внешний ключ)
   * `date` — дата расхода
   * `category` — категория (Транспорт, Проживание, Питание и т.д.)
   * `amount` — сумма
   * `description` — описание
